# Telegram Catalog Bot + Local Admin (Node.js)

Простой локальный проект:
- Telegram-бот с каталогом товаров
- Веб-админка для изменения товаров
- Логи действий
- Хранение в JSON (`data/products.json`, `data/logs.json`)

## 1) Установка

```bash
npm install
```

## 2) Переменные окружения

Создайте `.env` или экспортируйте переменные перед запуском:

- `TELEGRAM_BOT_TOKEN` — токен бота (обязательно для запуска бота)
- `ADMIN_TOKEN` — опционально, защита изменения товаров через API
- `PORT` — опционально, порт веб-сервера (по умолчанию `3000`)

## 3) Запуск

```bash
npm run dev
```

После запуска:
- Админка: `http://localhost:3000`
- API:
  - `GET /api/products`
  - `POST /api/products`
  - `GET /api/logs`

## 4) Как пользоваться ботом

1. Напишите боту `/start`
2. Отправьте `/catalog`
3. Выберите товар кнопкой

## Примечание

Если `TELEGRAM_BOT_TOKEN` не задан, веб-админка и API будут работать, но бот не запустится.
